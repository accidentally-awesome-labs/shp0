# shp0 codebase audit — verified findings (2026-09-26)

*Companion to the strategy report (`docs/strategy/`). Ground truth: `main@21b98b1` (2026-07-05), the only branch on GitHub.*

## Method

This audit is the verified evidence base for the strategy report. It was produced in three passes.

1. **Multi-agent reading.** Four agents each read one area of the monorepo in full:
   - data, tenancy and catalog (`packages/db`);
   - the commerce engine (cart, checkout, payments, Discounts, Collections);
   - web surfaces (`apps/web`: storefront, dashboard, admin, proxy);
   - identity, billing, operations and engineering process (`packages/auth`, billing, tests, tooling, tracker).
2. **Live probes.**
   - Throwaway Postgres 16 clusters, seeded up to 2,000 Stores, 200k Products and 600k Variants, running the repository's own schema SQL and functions.
   - A scratch `next build`.
   - The installed `stripe@22.3.0`, `better-auth@1.6.23` and `drizzle-kit@0.28.1` sources and typings.
   - The GitHub API and git object lookups for tracker claims.
3. **Adversarial re-verification.** A second agent per area re-checked every critical or high claim, and most mediums. Where it corrected the original, the corrected version is used and marked **[C]**. The final editor re-checked the I4 line citations against the source.

**The repository was never modified** (`git status` clean). Tracker issues #43–#60 are closed as "completed", but their cited commits do not exist (O1). None of their claimed fixes is assumed.

**Scope.** Every critical, high and medium finding, plus the lows that matter. Within each area, rows are ordered by severity.
